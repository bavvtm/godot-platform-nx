# Godot 4 for Nintendo Switch (overlay)

This repository contains a *Godot 4* platform overlay extension targeting the Nintendo Switch architecture via [devkitPro](https://devkitpro.org/) and [mesa-switch](https://github.com/danfromtico/mesa-switch.git). See the original [Godot Engine docs](https://docs.godotengine.org/en/stable/) for info about Godot.
